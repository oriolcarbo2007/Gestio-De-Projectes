Sobre los datos y el método

Dashboard de hoteles y alojamientos turísticos en Barcelona

DashboardSobre los datos y el método

Este dashboard muestra dónde se concentran los establecimientos hoteleros de Barcelona. Se ha creado con ayuda de una herramienta de IA a partir de un dataset abierto, sin servidor ni base de datos.

2. Columnas utilizadas

ColumnaUso en el dashboard
register_idIdentifica cada establecimiento y elimina duplicados
nameNombre en la capa de puntos
addresses_neighborhood_id, addresses_neighborhood_nameUnión con el mapa (BARRI en el GeoJSON)
addresses_district_id, addresses_district_nameFiltro y gráfico por distrito
geo_epgs_4326_lat, geo_epgs_4326_lonCoordenadas WGS84 para la capa de puntos
secondary_filters_nameFiltro por tipo o categoría, si el archivo la trae

3. Método

  1. Cada establecimiento cuenta una sola vez (se descartan filas repetidas con el mismo register_id). Se cuentan por barrio.
  2. La densidad divide el nº de establecimientos por la superficie del barrio (propiedad AREA del GeoJSON, en m², pasada a km²).
  3. Si una fila no trae código de barrio, se asigna con sus coordenadas comprobando en qué polígono del GeoJSON cae.
  4. El mapa usa clases con cortes fijos y una escala de un solo color (claro = pocos, oscuro = muchos). El cálculo se hace en el navegador con JavaScript (Leaflet, Chart.js y PapaParse).

4. Limitaciones

  • Cuenta establecimientos, no plazas ni habitaciones: un hotel pequeño pesa igual que uno grande.
  • Según el dataset, puede no incluir otros alojamientos como pensiones, albergues o apartamentos turísticos, que se publican en datasets separados.
  • Los valores absolutos favorecen a barrios grandes; la densidad por km² ayuda a compararlos, pero conviene normalizar también por población.
  • El GeoJSON de barrios es un proyecto de código abierto, no una fuente oficial.

5. Cómo reutilizarlo

En tu ordenador: abre index.html con doble clic y selecciona el CSV cuando la página lo pida.
En un servidor web: sube la carpeta con data/opendatabcn_allotjament_hotels-csv.csv y data/barris.geojson; los datos se cargarán solos.
